## Summary

This release adds a claim-bounded synthesis addendum for active-particle feedback kinetic-arrest diagnostics. It integrates the v0.2.0--v0.2.6 audit sequence and locks a conservative interpretation: noise-assisted annealing windows were observed in the implemented reduced surrogate; local feedback is geometry-dependent and not uniquely causal; high-frustration geometries include rescue-stable regimes and one persistent hard boundary.
